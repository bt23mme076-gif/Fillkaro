Questions

 

Is it free?

Yes. No account, no subscription, no ads.

Where is my data stored?

Only in your browser, in Chrome's local extension storage. Uninstalling FillKaro deletes it. You can export a backup file from Settings.

Does it work on Google Forms?

Yes — text answers, dropdowns, multiple choice and checkbox questions. Open the form link directly (not embedded inside another website).

Can it upload my resume?

No. Chrome doesn't let extensions pick files, so upload fields are left for you. You can save a public Drive link to your resume and FillKaro fills "Resume link" questions.

A field wasn't filled. What now?

Type it yourself and tap "Save my answers from this page" — it fills next time. If FillKaro matched something wrong, please open an issue with the question's wording.
